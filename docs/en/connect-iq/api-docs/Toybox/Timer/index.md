# Module: Toybox.Timer

## Overview

The Timer module allows access to a Timer object.

This Timer can be used to run code at some point in the future or at a regular interval.

Since:

API Level 1.0.0

App Types and Runtime Contexts:

-   Audio Content Provider

-   Glance

-   Watch App

-   Watch Face

-   Widget
