# 商户入驻

开发者面板现在包含“商户账户”标签页。开始商户入驻流程时，请选择该标签页，再选择“设置商户账户”，然后按照屏幕上的说明操作。

完成入驻后，需要等待审核。验证过程可能需要几天，期间可能会要求您提供其他信息。申请获批后，您会收到电子邮件通知。

## 开发者所在的受支持国家/地区

Connect IQ™ 变现系统面向在美国、加拿大、澳大利亚、新加坡以及欧盟大部分国家/地区设有法人实体的开发者开放。如果您不居住在以下国家/地区，或您的法人实体不在以下国家/地区注册，则无法注册变现系统：

| 地区 | 国家/地区 |
| --- | --- |
| 北美洲 | 美国和加拿大 |
| 欧洲 | 奥地利、比利时、克罗地亚、塞浦路斯、捷克、丹麦、爱沙尼亚、芬兰、法国、德国、直布罗陀、希腊、根西岛、匈牙利、爱尔兰、意大利、拉脱维亚、列支敦士登、立陶宛、卢森堡、马耳他、摩纳哥、荷兰、挪威、波兰、葡萄牙、罗马尼亚、斯洛伐克、斯洛文尼亚、西班牙、瑞典、瑞士和英国 |
| 亚太地区 | 澳大利亚和新加坡 |

**注意：** 此列表可能会发生变化。

## 计划费用

入驻过程中，系统会要求您支付计划费用。该费用为每年 100 美元，且不予退还。

## 企业实体

Connect IQ 变现系统支持个人/独资经营者和组织两类企业实体。选择企业实体类型时，如果您以个人身份注册且不属于注册公司，请选择“个人/独资经营者”；如果您是合伙企业或公司，请选择“组织”。

开始收款后，如需更改企业实体类型，必须联系 [`ConnectIQAppStoreAdmin@garmin.com`](mailto://ConnectIQAppStoreAdmin@garmin.com)。收款后更改企业实体类型可能会影响当年的税务申报。

## 法律文件

您必须提供法律信息来验证企业身份。所需文件包括带照片的身份证件、地址证明、税务信息证明、增值税文件，以及根据企业实体类型所需的其他信息。

| 企业类型 | 身份证明材料 |
| --- | --- |
| 个人和独资经营者 | 带照片的身份证件、国家身份号码证明、居住地址证明、个人税号证明和行业证明 |
| 个体企业 | 组织成立文件、地址证明和行业证明 |
| 组织 | 注册文件、地址证明、行业证明、所有权证明、税务信息证明和增值税文件 |

## 税务文件

要完成注册，必须提供税务文件。所需税务文件因注册国家/地区而异，系统会根据您的居住地址或企业地址要求不同的文件。

其中包括波多黎各，以及马恩岛和泽西岛。
