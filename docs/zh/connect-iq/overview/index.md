## 留下你的印记

使用Garmine设备传感器和功能构建独特的可穿戴体验是很容易的.使用可用的API和ANT+配置文件,你构建的应用程序将暴露在依赖我们的[purpose-driven devices](/connect-iq/compatible-devices/)的数百万客户面前.使用熟悉的语言,各种应用程序类型和有用的SDK,你将以新的和令人兴奋的方式吸引客户.

来吧，留下你的印记。
