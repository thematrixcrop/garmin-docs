# 留下你的印记

## 留下你的印记

借助 Connect IQ，您可以利用 Garmin 设备的传感器和功能构建独特的可穿戴体验。通过现有 API 和 ANT+ 配置文件，您构建的应用可以服务于数百万依赖[专为特定用途设计的设备](/connect-iq/compatible-devices/)的用户。熟悉的语言、多种应用类型和完善的 SDK，将帮助您以新颖而有趣的方式服务用户。

现在就留下你的印记。

## 使用 Connect IQ 构建

### 音频内容提供商应用

- 从第三方内容提供商同步音频内容
- 管理已下载的音频内容
- 自定义音频内容的播放体验

### 数据字段

- 自定义设备内置功能
- 以新颖、富有创意的方式呈现活动信息
- 访问 ANT+ 传感器和 ANT 通用通道
- 使用 FIT 记录捕获、显示、记录和分享数据

### 设备应用

- 获取对可穿戴设备的扩展访问能力
- 读取并记录 FIT 文件
- 访问加速度计
- 访问 ANT+ 传感器和 ANT 通用通道
- 使用 GPS 和传感器数据
- 使用 BLE 与手机或互联网通信
- 使用 FIT 记录捕获、显示、记录和分享数据
- 通过 OAuth 连接到需要身份验证的 Web 服务

### 小工具

- 提供一眼即可了解的信息
- 向主轮播添加自定义卡片
- 响应用户交互并创建自定义界面
- 访问 ANT+ 传感器和 ANT 通用通道
- 使用 GPS 和传感器数据
- 使用 BLE 与手机或互联网通信
- 通过 OAuth 连接到需要身份验证的 Web 服务

### 表盘

- 自定义默认表盘
- 构建色彩丰富、始终显示的表盘
- 使用绘图工具包、自定义字体和自定义位图
