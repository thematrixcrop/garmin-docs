# 进度条

当应用需要执行异步操作时，应明确告诉用户需要等待。进度条通过全屏界面传达操作进度。如果无法确定操作何时结束，可以使用不确定进度模式。

## 最佳实践

- 如果用户可能需要取消操作，请提供返回（Back）行为。

- 提供足够的信息，让用户了解当前正在执行的过程。

- 如果有多个过程依次执行，尽量用一个进度条表示整体进度；如果无法表示整体进度，则使用不确定进度，并通过提示文本告知用户当前状态。
