# Progress Bars

在您的应用程序需要做一些异步时,您应该提示用户需要等待的迹象.进步提供一个全页的体验,以传达进步.如果您没有已知的进步终点,您可以使用无限进步模式.

## Best Practices

- 如果用户想取消操作,提供后背行为.

- 提供信息,以便用户了解正在进行的过程.

- 如果有多个进程发生一个接一个,请试图在一个进步中表示这些进程的进步,或者使用无限进步.
