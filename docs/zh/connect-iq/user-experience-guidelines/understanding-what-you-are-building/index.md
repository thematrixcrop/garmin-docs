# 了解您正在构建的内容

确定用户是谁之后，下一步是确定他们想要完成什么。他们使用您的应用，是为了达成某个具体结果。请关注用户“雇佣”您的应用来完成的“任务”。这些任务可能是“我想快速、清晰地查看时间”，也可能是“我想快速查看关键统计数据，不必在无关信息中筛选”。

请思考：您想向用户传达的关键信息是什么？Garmin 设备上的应用应专注于快速向用户呈现关键信息，并尽量减少交互。需要深入查看的内容可以留给移动应用或 Web。哪些功能是必需的？再次强调，保持简单。

任何设计的可用性都取决于两个变量：用户和任务。Garmin 设备上的应用应帮助用户以最少的交互快速完成关键任务。需要深入查看的内容可以留给移动应用或 Web。

## 常见使用场景

Garmin 是运动员信赖的品牌，用户群体从想要开始运动的人一直延伸到耐力运动者。Connect IQ 可以让您的品牌或解决方案触达这一庞大用户群体。

### 自定义 Watch Face

Watch Face 不仅是 Garmin 可穿戴体验的主页，也是用户表达自我的机会。自定义 Watch Face 可以让您将品牌和创意带给用户。

### 第三方传感器

Connect IQ 允许第三方传感器制造商连接 Garmin 设备。传感器可以记录额外的活动信息，并在 Garmin Connect 中显示。

### 集成 Workout 内容

Connect IQ 允许开发者将自己的内容融入 Garmin 活动体验。

### 新活动

Garmin 支持多种活动，但 Connect IQ 开发者可以让用户记录设备原生不支持的 Workout，例如舞蹈、轮滑等。

### 将服务扩展到 Garmin 用户

Garmin 可穿戴设备旨在全天候佩戴。Connect IQ 应用让用户只需抬腕即可访问您的服务。

### 音乐服务

Connect IQ 允许音乐内容提供商将服务扩展到 Garmin 用户。内容可以通过 Wi-Fi 下载并安全存储在设备上，供用户之后播放。您还可以在应用中实现播放跟踪和订阅管理。

### Garmin 作为更广泛解决方案的一部分

有时需要构建涉及多种技术的解决方案。凭借可编程性、传感器和连接选项，兼容 Connect IQ 的设备通常可以成为更大解决方案的一部分。
