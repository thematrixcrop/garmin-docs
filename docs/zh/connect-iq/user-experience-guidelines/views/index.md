# 视图

视图是承载信息的全屏画布，可以显示文本、图形、动画和其他内容。

## 视图堆栈

Garmin 设备的屏幕空间有限，因此通常不会同时显示多个视图。视图会按层堆叠，用户通过返回（Back）行为移除当前视图。

## 视图转换

Garmin 用户界面工具包提供了多种转场，用于以动画方式将视图显示到屏幕上或移出屏幕。视图可以：

-   立即显示

- 从左、右、上或下方滑入或滑出

- 闪现到屏幕上


可以使用这些转场将页面推到另一个页面上方、移开页面以显示下方页面，或用新页面替换当前页面。

### 使用转场表达页面层级

Garmin 应用常见的一种模式是通过菜单层级进行交互。将菜单推送到屏幕上时，让菜单从右侧滑入；用户关闭菜单时，让它向右侧滑出。

### 使用转场表达页面循环

Garmin 应用的另一种常见模式是页面循环：主屏幕提供信息轮播，用户可以逐页浏览。此时可以使用上下按钮或上下滑动在页面之间导航，并通过滑动转场强化页面轮播的感觉。
