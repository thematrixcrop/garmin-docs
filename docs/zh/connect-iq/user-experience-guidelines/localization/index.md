# 本地化

Garmin 设备面向全球市场，Connect IQ 也是全球应用市场。同一款 Connect IQ 产品可能有多个本地化版本，支持不同语言或不同字符集。Connect IQ 允许一个设备应用适配这些差异。

Connect IQ 工具支持根据语言覆盖应用资源，包括文本和图形。支持以下语言：

- 保加利亚语
- 捷克语
- 丹麦语
- 德语
- 荷兰语
- 英语
- 爱沙尼亚语
- 芬兰语
- 法语
- 克罗地亚语
- 匈牙利语
- 印度尼西亚语
- 意大利语
- 日语
- 韩语
- 拉脱维亚语
- 立陶宛语
- 挪威语博克马尔文
- 波兰语
- 葡萄牙语
- 斯洛伐克语
- 斯洛文尼亚语
- 西班牙语
- 瑞典语
- 俄语
- 罗马尼亚语
- 泰语
- 土耳其语
- 乌克兰语
- 越南语
- 标准马来语
- 简体中文
- 繁体中文

开发 Connect IQ 应用时，应考虑如何让应用适配其他国家/地区和语言。

## 最佳实践

- 所有 Connect IQ 设备都支持英语，但并非所有设备都支持全部语言。仅支持英语不能算作本地化策略。

- Garmin 设备允许用户自定义距离、海拔、身高、配速、温度和重量的首选单位。显示这些类型的指标前，请先读取用户的单位偏好。

- 为译文留出足够空间。文字的高度和宽度可能会随显示语言而增减。可以使用 Connect IQ Simulator 在多种语言下测试文本。

- 尽可能使用图标，但要注意不同文化对图像和颜色的理解可能不同。

- 根据地区设置支持多种日期显示格式。

- 尽可能避免要求用户输入文本。
