# 融入视觉设计和产品个性

确定工作流程和交互模式后，就可以开始融入视觉设计。视觉设计需要同时体现你的品牌和目标产品的个性。

## 产品个性

Garmin 产品的个性各不相同，取决于目标用户、产品的核心用途、图形和工业设计，以及产品采用的硬件和技术。

### 屏幕技术

许多 Garmin 产品使用一种称为 Memory in Pixel（MIP）的屏幕技术。MIP 显示屏功耗很低，依靠反射光显示内容，因此在户外看起来最明亮。这种显示技术的颜色数量有限：有些设备最多提供 64 种颜色，有些只有 8 种，甚至只能显示黑白。

大多数使用 MIP 显示屏的 Garmin 产品提供 64 色调色板。

Garmin 设备使用的另一种常见屏幕技术是 LCD 或 AMOLED。这些屏幕可以显示更多颜色，画面更加鲜艳，但在户外使用时也会消耗更多电量。

### 视觉主题

不同 Garmin 设备使用不同的视觉主题。有些设备使用浅色背景上的深色文字，另一些则使用深色背景上的浅色文字。

选择视觉主题的原因不只在于美观。在 MIP 设备上，浅色背景上的深色文字主要用于活动场景，可以提供更好的对比度。由于屏幕依靠反射光，在户外环境中，白色背景和黑色文字能够实现最佳对比度。

在 Edge 产品上，视觉主题会根据时间变化。白天使用白色背景和黑色文字，以获得最佳对比度；夜间则使用黑色背景和白色文字，减轻低光环境下的视觉负担。

AMOLED 或 LCD 屏幕设备使用黑色背景上的浅色文字。深色视觉主题可以让 AMOLED 设备在界面中呈现丰富图像的同时延长电池续航。

### 排版

Garmin 设备有两种系统字体：文本字体和数字字体。文本字体用于文本数据和标签，数字字体用于数值数据。设备随附的系统字体已经过可读性测试，应尽可能使用。

Connect IQ 允许开发者将字体导入应用，但每种字体只能导入一个字号。自定义字体应当用于提供视觉强调或加入品牌元素。

### 页眉和页脚

应用通常会在视图顶部设置页眉。页眉可以包含少量文字或图标，帮助用户了解自己在应用中的位置。在颜色较少的 MIP 产品上，页眉通常使用纯色；在 LCD 或 AMOLED 显示屏上，页眉应使用渐变并逐渐融入黑色。

### 图像

在 LCD 或 AMOLED 屏幕设备上，背景中的细微图像可以为页面增添视觉点缀。

## 最佳实践

-   面向多个产品设计时，无论显示尺寸如何，都展示相同的内容。依靠标准模式和系统字体，让内容适配不同的显示尺寸和分辨率。

-   将最重要的信息放在最显眼的位置。Device app 不应成为用户注意力的焦点，应清晰展示相关信息，让用户迅速回到要完成的任务。

-   如果只能选择一种主题，请优先采用深色背景上的浅色文字。它在默认使用深色背景的设备上效果自然，在 AMOLED 显示屏上也不会显得突兀。浅色背景上的深色文字主题更适合面向户外活动、使用 MIP 显示屏的应用。

-   选择能够体现品牌的主题色，并将其用于图标和页眉。

-   系统字体已经过可读性测试，但不同设备上的字体大小会有所不同。设备上的文字应尽量简短，或让文字分布到多个页面。
