# 发展概念

明确要解决的问题和目标用户后，就可以设计满足这些需求的方案。接下来，我们将了解如何通过重要内容和工作流程实现用户目标。

## 应用类型

与其他平台不同，Connect IQ 应用具有特定的应用类型，用于定义它们在设备界面中的位置和交互方式。选择应用类型时，应从用户要解决的问题出发：如果目标是增强训练体验，应创建数据字段；如果希望用户在活动之外监测某项指标，应使用设备应用；如果应用中的信息会在一天内持续更新，可以为设备应用添加速览。

应用类型会限制可采用的工作流程：

- 表盘和数据字段不接收用户输入，但用户可以在设备上进入应用定义的设置流程，或在移动端编辑设置。

- 经用户允许，数据字段可以在用户达到里程碑时显示提醒。

- 数据字段可以将额外信息记录到活动文件中。

- 小工具的基础页面会限制可用输入，以便用户在轮播中导航。在按钮设备上，通常使用上下按钮完成导航。


### 表盘

表盘是 Garmin 可穿戴设备的主屏幕。表盘不接收直接的用户输入，但可以在 Connect IQ 移动应用中提供可编辑的设置。在 API 级别 3.2 及更高版本的设备上，表盘还可以提供可启动的设备端配置流程。

![表盘](/connect-iq/resources/ux-guide/watch-face.png)

### 数据字段

数据字段是可以在 Garmin 活动中显示信息的插件。安装后，用户可以将数据字段放置在活动的任意页面中。为了保持 Garmin 的使用体验，数据字段不接收输入，但可以在 Connect IQ 移动应用中提供可编辑的设置。在 API 级别 3.2 及更高版本的设备上，数据字段还可以提供可启动的设备端配置流程。

![数据字段](/connect-iq/resources/ux-guide/data-fields.png)

### 小工具和速览

小工具是用户可以快速浏览的应用轮播列表。基础页面支持的输入有限，但可以推入其他页面，让用户深入查看信息。Garmin 于 2019 年推出了速览功能。速览是可滚动的关键数据列表，每个列表项显示一个指标，用户可以选择任意速览查看详细信息。小工具和速览在一段时间没有操作后都会超时。

![小工具](/connect-iq/resources/ux-guide/widgets.png)

![速览](/connect-iq/resources/ux-guide/glances.png)

### 音频内容提供商

音频内容提供商作为音乐播放器的插件运行，用户可以将其选为音频来源。启动音乐播放器后，用户可以使用与应用通信的媒体控制；进入媒体播放器子菜单并点击应用图标，还可以进行更深入的操作。在这里，应用可以提供下载、管理内容和开始播放等流程。

![音频内容提供商](/connect-iq/resources/ux-guide/audio-content-providers.png)

### 设备应用

设备应用是可以启动且不会自动超时的体验。设备应用可以接收输入、操作页面栈，并与云服务和无线传感器通信。用户从主页面返回即可退出设备应用。在 API 级别 4.0 及更高版本的设备上，还可以为设备应用添加速览。设备应用的例子包括活动记录应用、游戏，以及将丰富内容集成到设备上的应用。

![设备应用](/connect-iq/resources/ux-guide/device-apps.png)

## Connect IQ 应用和信息架构

Connect IQ 应用通常遵循“信息优先”的设计原则：先展示关键信息，再通过有限的交互提供更多内容。

- 数据字段始终显示关键信息。任何自定义设置流程都要求用户进入数据字段设置。

- 小工具应始终在基础页面显示核心信息，也可以让用户进入后续流程查看更多内容。
