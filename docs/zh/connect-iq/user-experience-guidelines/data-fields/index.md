# 数据字段

Garmin 活动通常会向用户提供由数据字段页面组成的页面循环。在活动设置中，用户可以使用预定义的数据字段布局划分页面，并在每个区域中分配显示相关活动指标的数据字段。

自定义数据字段可以扩展 Garmin 的训练体验：计算新指标，通过 ANT 或 Bluetooth Low Energy 传感器读取数据，显示提醒，并将信息记录到 Garmin Connect。

直接处理用户输入属于活动体验本身。数据字段的输入应来自活动、传感器或配置。

## 数据字段布局

设计数据字段时，不能假设用户一定会将它以全屏形式显示。有些用户喜欢在多个页面上各放一两个数据字段，另一些用户则会在页面中填入大量信息。因此，数据字段既应能在完整页面中清晰呈现，也应能在较小的显示区域中提供摘要视图。

### 遮挡

根据用户在页面上的放置位置，数据字段的部分可视区域可能会被屏幕边缘的曲线遮挡。这会减少标签或其他设计元素可用的空间。Connect IQ 会告知可视区域的顶部、左侧、右侧或底部是否被遮挡。您可以据此调整布局，例如将标签移到下方，为其留出最大的可视区域。

## 设置

数据字段不接收直接用户输入，但用户可以通过移动端设置和设备端设置进行配置。移动端设置允许用户修改一组应用属性，属性发生变化时应用会收到通知。

在 System 4 及更高版本的设备上，Connect IQ 数据字段可以在表盘中内置可启动的配置流程。数据字段设置可从活动设置菜单中的 *Connect IQ Settings* 菜单项进入；在设置流程中，可以推入和弹出视图来完成配置。

## 警报

由于数据字段位于页面循环中，训练期间不一定始终可见。如果需要提醒用户某个事件，可以向屏幕推送全页提醒。用户可以关闭提醒，或者提醒会在一段时间后自动消失。

默认情况下，数据字段提醒处于禁用状态。用户需要进入活动的*设置* -> *提醒* -> *Connect IQ*，然后选择要启用提醒的应用。

## 将信息记录到 Garmin Connect

数据字段可以在活动文件中定义并记录最多 16 个指标。这些指标最多可以每秒记录一次，并作为活动、分段或摘要信息的一部分保存。如果指标作为活动数据记录，就可以在 Garmin Connect 中显示为面积图。除数据本身外，还可以控制可翻译的标签、指标名称和面积图颜色。

## 最佳实践

- 如果数据字段只显示一个指标，实现 *SimpleDataField* 就可以自动处理标签和布局逻辑。

- 使用设备端设置流程处理身份验证、无线传感器配对和配置流程。

- 对于记录的数据，应选择符合品牌且与 Garmin Connect 网页版和移动端活动配色协调的颜色。
