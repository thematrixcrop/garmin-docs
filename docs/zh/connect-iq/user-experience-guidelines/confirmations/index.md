# 确认

确认用于向用户提问，并获得“是”或“否”的回答。确认通常只显示文字，让用户做出肯定或否定的选择，适合在重要操作前增加一层必要的确认。

![](/connect-iq/resources/ux-guide/confirmations.png)

## 最佳实践

- 确认会增加操作步骤，因此只在确有必要时使用。没有必要时不要打断用户。

- 原生确认的选项可能是“是（Yes）”或“否（No）”，也可能根据产品个性使用视觉提示。设计时应兼顾这两种情况。

- 对话框中的问题应足够具体，让用户理解自己要做的选择，并确保问题可以用“是”或“否”回答。
