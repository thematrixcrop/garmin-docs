# 用户体验指南

Connect IQ 允许第三方开发者将自己的设计和经验带到 Garmin 产品中。本文介绍面向 Garmin 用户设计应用时应遵循的一些原则。

## 面向客户的设备

与其他平台不同，Garmin 产品针对各自服务的用户群体：

- **Edge 系列**面向自行车用户，提供专业的自行车电脑体验。

- **fēnix® 系列**面向户外活动用户，提供适合户外场景的可穿戴体验。

- **Forerunner® 系列**面向跑步者和铁人三项运动员。

- **vívoactive® 和 Venu® 系列**面向追求积极生活方式的用户。

- **Oregon®、GPSMAP® 和 Rino® 系列**面向需要手持地图设备的用户。

选择要支持的产品时，请结合这些用户群体和使用场景进行判断。

## 可穿戴设备用户

“Watch”也有“观察”的含义。设计智能手表应用时，请记住，手表最适合用来快速观察信息。优秀的可穿戴应用不会妨碍用户完成手头的事情，而是让用户快速获取关心的信息并完成关键操作。

可穿戴设备是最具个人属性的计算平台之一。Garmin 设备可以访问多种传感器，包括 GPS、心率监测器、罗盘、加速度计、气压计、陀螺仪和 ANT+ 网络。应以有趣的方式让用户了解与自己相关的信息。

## 骑行用户

Edge 用户希望自行车电脑无论骑行时间长短或天气如何都能稳定工作。请创建能够融入 Garmin 现有骑行体验的应用，而不是用自己的体验取而代之。无论应用体验多么出色，用户都不希望它缩短设备续航。

## 户外用户

户外用户希望专注于户外活动，而不是应用本身。应用应当辅助他们完成目标，设计时也不要假设设备始终处于联网环境。
