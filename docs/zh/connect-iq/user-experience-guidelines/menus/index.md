# 菜单

应用可以创建使用设备默认视觉风格的菜单。如果希望体现自己的品牌风格，也可以使用自定义菜单。

默认情况下，菜单会从列表末尾循环回到开头，也可以在末尾继续进入另一个菜单。如果选项列表很长，应采用可预测且有意义的排序方式，例如按字母排序，或将选项分成相关类别。用户会在父菜单中看到类别名称，选择“父菜单”项后即可查看子菜单中的选项。

## 选择菜单

当用户需要浏览可选项目列表时，可以使用选择菜单。菜单顶部和底部的标题及说明文字可以为选项提供上下文。

建议选择使用图标或图像来突出选择的意义:

## 设置菜单

通常可以通过基础页面的菜单（Menu）行为访问设置菜单。设置菜单允许用户在应用中修改全局设置。菜单顶部和底部的标题及说明文字可以为选项提供上下文。

![](/connect-iq/resources/ux-guide/settings-menu.png)

有关颜色、字体和图标使用方式的视觉设计指导，请参阅《产品设计附录》。

## 最佳实践

- 根据需要将菜单分成类别。通常每个列表最多包含 7 个项目。

- 对于设置菜单中的开/关选项，使用切换开关。

- 对于设置菜单和选择菜单中的多选项，使用复选框。

- 对于其他选择，为用户提供二级菜单查看全部选项，并在父菜单项的副文本中显示当前选择。

- 对于较长的信息，可以使用自定义底部元素提示下方还有内容；当用户越过列表末尾时，再切换到新菜单。
