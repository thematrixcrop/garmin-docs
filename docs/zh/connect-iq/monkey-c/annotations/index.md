# 注解

子C允许将符号与类或模块方法和变量联系起来.这些符号目前已被编译器生成的`debug.xml`文件中写入,但将来可以在不改变子C语法的情况下添加新的功能:

```java
(:debug) class TestMethods
{
    (:test) static function testThisClass( x )
}
```

下列注释对子C编译器具有特殊意义:

**:background**

表示可用于背景进程的代码区块.

**:debug**

在编译时,以此注释装饰的代码块不会被包含在发布构建中.

**:glance**

表示在Glance模式中运行时可用的代码区块.

**:release**

在编译时,用此注释装饰的代码区块不会被包含在调试构建中.

**:test**

指用于运行无恶单元测试的测试案例,并且在编译时被排除在应用中.

**:typecheck**

用此注释装饰的代码区块可以引导类型检查器执行/避免某些检查.

**:initialized**

用此注释装饰的成员变量指示类型检查器,认为变量在引用之前将被初始化.

**:extendedCode** (*API 级别 5.1.0*)

扩大代码空间中的代码在运行时间内按要求进行页面化.对于支持的设备,这提供了16兆字节的代码空间,超出了加载到堆中的内容.为支持的产品构建时,编译器将将这些功能移动到扩大代码空间中.扩大代码空间中的代码在内存中通过最近使用的 space策略页面化,但如果必须将代码页面化,则可能会出现性能处罚.性能依赖的代码应保持在扩大代码空间之外以避免额外的性能.

**:optimizer(do\_not\_remove)**

用此注释装饰的常数指示优化器在引用常数时禁用常数替换. 相反,常数将在运行时查看.
