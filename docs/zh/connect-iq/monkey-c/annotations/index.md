# 注解

Monkey C 允许将符号与类或模块的方法和变量关联起来。编译器会将这些符号写入生成的 `debug.xml` 文件，未来可以在不修改 Monkey C 语法的情况下利用它们添加新功能：

```java
(:debug) class TestMethods
{
    (:test) static function testThisClass( x )
}
```

以下注解对 Monkey C 编译器具有特殊含义：

**`:background`**

表示可供 Background 进程使用的代码块。

**`:debug`**

标记了此注解的代码块不会在编译发布版本时包含在内。

**`:glance`**

表示在 Glance 模式运行时可用的代码块。

**`:release`**

标记了此注解的代码块不会在编译调试版本时包含在内。

**`:test`**

表示用于 Run No Evil 单元测试的测试用例；这些代码会在编译时从应用中排除。

**`:typecheck`**

标记了此注解的代码块可以指示类型检查器执行或跳过特定检查。

**`:initialized`**

应用于成员变量时，指示类型检查器可以安全地假定该变量在被引用前已经初始化。

**`:extendedCode`**（*API 级别 5.1.0*）

扩展代码空间中的代码会在运行时按需分页加载。对于受支持的设备，这会在已加载到堆中的代码之外额外提供 16 MB 的代码空间。为受支持的产品构建时，编译器会将标记的函数移入扩展代码空间。扩展代码空间中的代码会按照“最近使用”策略分页到内存；如果代码需要分页加载，可能会产生性能开销。对性能敏感的代码应留在扩展代码空间之外，以避免额外延迟。

**`:optimizer(do_not_remove)`**

应用于常量时，会指示优化器不要将引用该常量的代码替换为常量值，而是在运行时查找该常量。
