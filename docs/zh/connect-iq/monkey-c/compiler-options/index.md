# 编译器选项

以下是 `monkeyc` 的命令行选项：

| 短选项 | 长选项 | 参数 | 说明 |
| --- | --- | --- | --- |
| `-d` | `--device` | 设备标识符 | 构建设备可执行文件时必需。指定目标设备。 |
| `-e` | `--package-app` | 无 | 指定输出为用于上传到应用商店的 `IQ` 文件。 |
| `-f` | `--jungles` | 以冒号分隔的 Jungle 文件路径列表 | **必需。** 每个 Jungle 文件指定一个要包含的项目，可以包含一个应用项目和多个 Monkey Barrel 项目。 |
| `-g` | `--debug` | 无 | 输出调试信息。 |
| `-h` | `--help` | 无 | 输出帮助信息。 |
| `-k` | `--profile` | 无 | 在可执行文件中包含性能分析信息。带有性能分析信息的可执行文件在设备上运行时，设备会生成可在模拟器中分析的性能数据。 |
| `-l` | `--typecheck` | `0` = 关闭，`1` = 渐进，`2` = 信息，`3` = 严格 | 更多信息请参阅 [Monkey 类型](/connect-iq/monkey-c/monkey-types/)章节。 |
| `-o` | `--output` | 输出文件 | **必需。** 指定编译器输出。 |
| `-O` | `--optimization` | `0` = 无，`1` = 基本优化，`2` = 快速优化，`3` = 慢速优化，`p` = 性能优化，`z` = 代码空间优化 | 调试构建默认为 `1`，发布构建默认为 `2`。数字级别后可以添加字母，例如 `-O 2pz`。 |
| `-r` | `--release` | 无 | 不在 PRG 中包含调试信息。 |
| `-t` | `--unit-test` | 无 | 在构建中包含单元测试。 |
| `-v` | `--version` | 无 | 输出编译器版本。 |
| `-w` | `--warn` | 无 | 默认关闭。显示编译器生成的构建警告。 |
| `-y` | `--private-key` | 开发者密钥路径 | **必需。** 指定用于签署 `PRG` 或 `IQ` 文件的开发者密钥。 |

## 调试日志

如果遇到 `monkeyc` 编译器问题，需要生成日志并随报告提交。可以使用以下选项创建调试日志：

| 长选项 | 参数 | 说明 |
| --- | --- | --- |
| `--debug-log-level` | `0` = 错误，`1` = 基本调试，`2` = 中级调试，`3` = 详细调试 | 指定输出的详细程度。 |
| `--debug-log-output` | 要生成的日志文件路径 | 指定要创建的日志文件路径。 |
| `--debug-log-device` | 设备标识符 | 构建 Monkey Barrel 时，将日志限制到指定设备。 |

请注意，日志级别越高，包含的源项目细节越多。如果希望保护项目隐私，请将日志级别限制为 `1` 或更低。更详细的日志有助于 Garmin 调试问题。

## 功能控制选项

以下选项用于控制不同功能：

| 长选项 | 参数 | 说明 |
| --- | --- | --- |
| `--disable-api-has-check-removal` | 无 | 禁止优化移除 API `has` 检查。 |
| `--disable-v2-opcodes` | 无 | 禁止生成 V2 操作码。 |

## 私有选项

这些选项通常已经预先设置，一般不需要使用：

| 短选项 | 长选项 | 参数 | 说明 |
| --- | --- | --- | --- |
| `-a` | `--apidb` | `api.db` 路径 | 指定 API 链接信息的路径。 |
| `-b` | `--apimir` | `api.mir` 路径 | 指定 API 类型信息的路径。 |
| `-i` | `--import-dbg` | `api.debug.xml` 路径 | 指定 API 调试信息的路径。 |
| `-p` | `--project-info` | `projectInfo.xml` 路径 | 指定 SDK 项目定义的路径。 |
