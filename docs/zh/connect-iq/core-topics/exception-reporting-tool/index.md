# 错误报告应用程序（ERA）

应用发布到商店后，可以使用 ERA 工具查看应用的崩溃情况。如果应用在设备上崩溃，ERA 服务器会收集并汇总错误报告。崩溃发生后，这些报告最多可查看 30 天。该工具位于 SDK 的 `bin` 文件夹中。

## 入门

要启动图形 ERA 工具，可以在 Visual Studio Code 的命令面板中运行 *Monkey C: Start ERA Viewer* 命令，或者使用[命令行](#command-line)。首次运行工具时会出现 *Login Prompt* 窗口，要求您登录开发者账户。完成登录后，工具会下载应用列表并填充应用选择列表。

<a id="command-line"></a>
### 命令行

您可以从命令行启动图形 ERA 工具，只需在当前 SDK 的 **bin** 文件夹中运行 `java -jar era.jar`。

ERA 工具也可以直接从命令行获取单个应用的崩溃报告：在当前 SDK 的 **bin** 文件夹中运行 `era` 命令即可。工具会以 JSON 格式输出指定应用的崩溃报告。请注意，无论使用哪种方式首次启动 ERA 工具，如果之前尚未登录，系统都可能要求您登录开发者账户。

```
> era [-a <arg>]
```

| 参数 | 定义 |
| --- | --- |
| `-a <arg>` | 要检索崩溃报告的应用 UUID |
| `-h` | 输出帮助文本 |

## 查看应用设置

![](/connect-iq/resources/programmers-guide/era_manage_apps.png)

“Manage Apps”窗口用于查看与开发者账户关联的应用。选择菜单中的 **Settings > Manage Apps** 即可打开该窗口。应用列表按颜色标记，方便识别应用状态。

| 字体样式 | 应用状态 | 可查看崩溃报告 |
| --- | --- | --- |
| Normal | 已发布的应用 | 是 |
| Gold | Beta 应用 | 是 |
| Strikethrough | 应用已隐藏 | 否 |

在此窗口中，您可以重新排列应用并修改应用设置。要调整顺序，请选择一个应用，然后点击 **∧** 或 **∨** 按钮。窗口中的应用顺序会反映在崩溃报告视图的应用选择框中。要修改应用设置，请在列表中选择应用，然后点击 **i** 按钮。

![](/connect-iq/resources/programmers-guide/era_app_info.png)

在“Application Settings”窗口中，您可以将应用从崩溃报告视图的下拉列表中隐藏。如果勾选 **Hide this app**，该应用就不会显示在崩溃报告视图的应用列表中。

## 查看崩溃报告

![](/connect-iq/resources/programmers-guide/era_report_view.png)

崩溃报告视图允许您查看应用最近 30 天内上传的所有崩溃报告。您可以在窗口顶部选择要查看其报告的应用。选择应用后，最新报告会从服务器下载。窗口左侧窗格显示崩溃报告列表，每次独立崩溃都会标明发生崩溃的文件名、函数和行号。在左侧窗格中选择某次崩溃后，右侧窗格会显示其详细信息。右侧窗格顶部的 **Fixed** 复选框可用于标记该次崩溃是否已修复。修复状态会在应用运行和 SDK 升级后保留。修改 **Sort By** 选择器中的值，可以更改当前报告的排序顺序。

| 字体样式 | 崩溃状态 |
| --- | --- |
| Normal | 崩溃已查看。 |
| Bold | 崩溃尚未查看。 |
| Strikethrough | 崩溃已标记为已修复。 |
