# 测试应用

![](/connect-iq/resources/programmers-guide/beta_app.png)

Connect IQ 测试应用允许开发者在不发布应用的情况下，在生产线中测试应用设置和 Garmin Connect 集成。

上传测试应用将使您能够在生产环境中分阶段部署您的应用。要使用此功能，您需要使用 [UUID 创建器](https://www.uuidgenerator.net/) 在清单中创建备用应用 ID。测试应用将显示在您上传的应用中，您可以将它们下载到 Garmin 设备。下载后，您可以在 Garmin Connect 和 Garmin Express 中编辑应用设置，并在 Garmin Connect 中测试您的开发数据字段。上传测试应用后，您可以根据需要多次更新测试版本。准备发布应用时，在清单中将应用 ID 更改为您的生产版本，并在不勾选"测试应用"复选框的情况下上传它。请注意，该应用将具有与最终应用不同的商店标识符，并且测试应用的 URL 在您的账户之外不可见。
