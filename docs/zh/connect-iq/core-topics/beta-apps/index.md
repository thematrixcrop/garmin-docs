# 测试应用

![](/connect-iq/resources/programmers-guide/beta_app.png)

Connect IQ 测试应用允许开发者在不正式发布应用的情况下，在生产环境中测试应用设置和 Garmin Connect 集成。

上传测试应用可以让您在生产环境中分阶段部署应用。要使用此功能，请通过 [UUID Generator](https://www.uuidgenerator.net/) 在清单中创建备用应用 ID。测试应用会显示在您上传的应用列表中，您可以将其下载到 Garmin 设备。下载后，您可以在 Garmin Connect 和 Garmin Express 中编辑应用设置，并在 Garmin Connect 中测试开发者数据字段。上传测试应用后，您可以根据需要多次更新测试版本。准备发布应用时，请在清单中将应用 ID 更改为生产版本，然后取消选中 **Beta App** 复选框并重新上传。请注意，测试应用拥有不同于最终应用的商店标识符，其 URL 在您的账户之外不可见。
