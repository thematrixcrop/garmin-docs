# Garmin Connect IQ 应用审核指南

**最后更新：** 2021 年 10 月 13 日

使用 Connect IQ SDK，开发者可以为兼容 Garmin Connect IQ 的设备创建应用，并通过 Connect IQ 商店分发。Connect IQ 是 Garmin 的重要战略项目，旨在借助共同的用户群、多样化的设备组合和强大的指标能力，让您的创意成为现实。感谢您希望开发 Connect IQ 应用，我们希望您的开发过程顺利并取得成功。

为了帮助您创建真正服务于用户的应用，我们制定了这份 Connect IQ 应用开发者指南（以下简称“**指南**”）。本指南适用于使用 Connect IQ SDK 进行的任何开发或创建工作，包括设备应用、小工具、表盘、自定义数据字段和音频内容提供者应用。为便于阅读，本文使用“应用”一词统称上述所有类别。

本指南并非完整的规则清单。即使某个应用没有明确违反本指南，我们仍可能因为它具有潜在危害而暂停或从 Connect IQ 商店下架。换言之，提供本指南并不代表我们放弃适用法律或 [Connect IQ 开发者协议](https://developer.garmin.com/downloads/connect-iq/sdks/agreement.html)（您应仔细阅读）赋予我们的任何权利。

## 摘要

我们建议您阅读完整指南。以下是主要内容的概要：

1. **适当的内容和主题。** 您需要对自己的应用负责。对于我们认为危险、冒犯、不适当或违法的内容或主题，我们可能拒绝或下架应用。请注意，航空、医疗或支持用户生成内容等特定类型的应用，只有在满足额外要求时才可能获准发布。

2. **性能要求。** 我们希望用户获得最佳体验。如果应用无法正常运行、缩短 Garmin 设备的电池续航或影响其他功能，或者经常崩溃，应用可能会被拒绝或下架。

3. **推广和变现应用。** 用户体验从您如何推广、描述和变现应用开始。您必须以诚实、公平的方式面向用户和其他应用开展这些工作。

4. **尊重他人的权利。** 未经许可，不得使用他人的受版权保护内容或其他知识产权。应用不得以违反 [Connect IQ 开发者协议](https://developer.garmin.com/downloads/connect-iq/sdks/agreement.html) 或隐私法律的方式使用数据。

5. **执行。** 我们希望开发者遵守本指南。如果未遵守，我们保留采取措施保护用户的权利。

以下章节将详细说明这五个主题。

## 详细指南

**1.** **适当的内容和主题**

您需要对应用承担最终责任，包括应用的软件和内容、应用在 Connect IQ 商店中的描述、应用用户的行为，以及对法律、法规和合同的遵守。本指南列出了需要避免的内容和主题问题。

**a.** **禁止的内容**

应用不得包含违法、有害、淫秽、不适当或冒犯性的内容。禁止应用包含、链接到或鼓励创建以下类型的内容：

- 性或淫秽内容，包括色情内容、任何旨在提供性满足的内容或服务、与兽交或非自愿性行为有关的内容，以及对性器官或性行为的露骨描述或展示；

- 欺凌、骚扰和虐待；

- 脏话，以及诽谤、欺诈、侵权或其他违法内容；

- 主要用于向网站引导联盟营销流量的垃圾邮件或广告导向内容，或主要目的在于展示广告的内容；

- 赌博；

- 任何其他不适当或冒犯性的内容。对于我们认为会给 Garmin 带来责任风险、可能伤害用户或第三方，或可能损害我们声誉的应用，我们保留拒绝或下架的权利。这包括但不限于直接或间接违反我们其他条款或指南的内容。

**b.** **人身安全**

应用不得威胁用户或任何其他人的人身安全或福祉。对于我们认为不安全或可能直接、间接造成伤害的应用，我们保留拒绝的权利。这也包括可能制造虚假安全感的应用，例如“安全意识”应用。

请避免以下具体问题：

- **有害挑战：** 应用不得鼓励或挑战用户以可能对自己或他人造成人身伤害的方式行动或使用设备。例如，不得挑战用户以可能导致受伤的方式进行锻炼或活动，也不得挑战用户饮用过量酒精。

- **危险活动：** 我们禁止设计用于水肺潜水、自由潜水、跳伞、定点跳伞和极限飞行运动等危险活动期间的应用，即使应用是为某款专为这些活动设计的 Garmin 产品开发的。例如，您可以为 Garmin Descent 系列潜水表增加功能，但应用不应仅用于用户的潜水过程之中。

- **暴力：** 不允许应用助长或鼓励无端暴力、侵犯人权、家庭暴力、虐待儿童或动物，以及其他类似的伤害用户或他人的行为。

- **毒品和危险产品：** 应用不得宣传使用非法药物、烟草或电子烟产品、过量酒精、未经批准的物质，以及非法或危险产品。

- **特定航空使用场景：** 我们会允许适当的航空主题应用，但除法律要求的其他免责声明外，航空应用（表盘除外）还必须包含以下免责声明：“警告：本应用仅用于飞行中辅助，不应作为主要信息来源。如果应用包含气压式高度计，它将在增压飞机中无法正常工作，也不应在增压飞机中使用。”

- **受监管的活动：** 您需要独自负责确保应用遵守法律法规，并包含法律要求的免责声明。在适当情况下，尤其是应用涉及医疗、法律或金融服务等受监管活动时，我们建议您寻求独立的法律意见。

**c.** **医疗应用**

如果应用用于诊断、治愈、缓解、治疗或预防疾病或其他病症，您必须准备好提交相关监管机构的文件，证明应用获准在目标市场使用。否则，您必须修改应用的描述、功能和行为，确保它不会暗示用于诊断、治愈、预防、缓解或治疗疾病或其他病症，而是仅用于提供信息。即使应用已获监管机构批准，我们仍保留根据本指南接受或拒绝应用的权利。

**d.** **不得包含恶意软件或有害应用**

我们不允许引入或利用安全漏洞的应用。这包括但不限于包含或启用病毒、间谍软件、禁用代码，或其他旨在损害设备或服务器、侵犯用户隐私的恶意软件。您需要在提交应用前自行检查其中是否存在恶意软件。

**e.** **不得挖掘加密货币**

禁止使用 Garmin 设备挖掘加密货币的应用。

**f.** **不得面向 13 岁以下儿童**

禁止设计供 13 岁以下儿童使用的应用。面向普通受众的应用不受此限制，除非您知道该应用被 13 岁以下儿童使用。

**g.** **用户生成的内容**

如果应用提供允许公众或其他用户发布用户生成内容的功能，您需要负责根据需要审核内容，防止出现违法、侵权或不适当内容。“用户生成的内容”包括用户或第三方提交或上传的文本、图像、声音或其他数据。

您必须：

- 与最终用户达成协议，禁止违法、有害、淫秽、不适当或冒犯性的内容（参见上文 1(b)“禁止的内容”）；

- 保持用户可以举报不适当或禁止内容的渠道；

- 发布符合 DMCA 要求的政策，以删除侵犯第三方知识产权的内容。

如果您未能审核应用中的用户生成内容，我们保留采取措施暂停或下架应用的权利，就像是您自己的内容违反了本指南一样。

**2.** **性能要求**

用户希望在使用 Garmin 产品时获得高质量体验。本指南旨在帮助应用达到用户的预期。

**a.** **不得损害 Garmin 体验**

应用不应造成损害。应用不得干扰其他应用或功能的使用和体验，例如活动体验、电池续航和设备性能。

请避免以下具体问题：

- **干扰其他功能：** 不允许应用损坏、扰乱或未经授权访问用户的 Garmin 设备、其他设备或计算机、网络、服务器、应用程序编程接口（API）或服务。应用不应要求更改系统设置，从而对设备上其他功能的性能产生不利影响，例如要求用户断开 Garmin 设备与已配对兼容智能手机的连接。

- **消耗电池续航：** 应用不应导致 Garmin 产品无法达到预期的电池续航，不应导致其他应用运行变慢，不应尝试未经授权访问数据，也不应以其他方式破坏宣传中的或用户期望的体验。

- **覆盖用户数据：** 不允许应用覆盖已同步到用户 Connect 账户的信息，此类数据字段通常来自 Garmin 设备本身，例如速度或距离。我们希望维护 Garmin 设备和软件收集或生成的数据值的完整性和可靠性。

- **可能损害设备的功能：** 应用不应要求或鼓励以可能损害 Garmin 设备的方式使用设备。例如，应用不应设计用于会让设备暴露在有害高温或水压下的活动。

- **提交前测试：** 提交时，应用应已完成、经过测试并可以使用。您应确保应用提供稳定、吸引人且响应及时的用户体验。应用不应包含失效的链接或功能。

**b.** **支持**

我们不负责为您的应用提供客户支持或处理投诉。您应向用户清楚说明支持政策和支持范围。您需要履行自己作出的支持承诺。

**3.** **尊重他人的权利，包括知识产权和隐私权**

**a.** **不得侵权**

您不得侵犯任何版权、商标、专利、商业秘密或其他形式的知识产权（“**IP**”）。您必须拥有应用中包含或使用的全部知识产权，或已获得使用许可。这包括应用的软件和内容（下文讨论的用户生成内容除外）、开发者账户名称，以及您在 Connect IQ 商店推广应用时使用的徽标、图像和内容。

您需要负责确保知识产权合规并避免侵权。以下是一些建议（不是法律意见）：

- **寻求法律意见：** 如果不确定使用知识产权是否构成侵权，请咨询律师。第三方知识产权的使用是否侵权、是否获得适当许可或是否属于合理使用，不应由我们判断。

- **获得许可：** 使用他人材料前，您需要从知识产权所有者处获得必要的许可。请以书面形式取得许可、保留许可记录，并确保遵守所有条款和条件。

- **谨慎使用品牌名称和徽标：** 应用可能是他人产品或品牌的理想补充，但这并不意味着您有权使用对方的知识产权。在提及非自有品牌，或使用不属于您的徽标或名称前，请务必谨慎。

- **询问知识产权所有者：** 如果对他人的知识产权有疑问，应询问知识产权所有者，而不是我们（Garmin 的知识产权除外）。

**b.** **Garmin 的 DMCA 政策**

Garmin 维护 DMCA 政策，供知识产权所有者向 Garmin 举报涉嫌侵权的内容。在某些情况下，我们可能需要根据该政策删除或暂停应用。政策和更多详情请参阅我们的[使用条款](https://www.garmin.com/en-US/legal/terms-of-use/)。

Garmin 的 DMCA 政策不能替代您为审核用户生成内容而制定自己的政策。不过，在某些情况下，如果用户生成的内容侵权，我们可能需要对您的应用采取措施。

**c.** **隐私和数据使用**

如果应用收集和处理任何用户数据，包括个人数据，您必须遵守隐私法律及其他适用的法律法规，也必须遵守 [Connect IQ 开发者协议](https://developer.garmin.com/downloads/connect-iq/sdks/agreement.html) 中规定的所有隐私要求。

请注意以下一般事项（不是法律意见）：

- **数据最小化：** 在收集和使用个人数据前，请仔细考虑。尽可能减少个人数据的收集、处理和保留是最佳实践，而且通常也是法律要求。

- **通知：** 发布并提供您自己的隐私政策或其他通知，说明您如何处理个人数据，以及用户如何联系您以行使隐私权。不能依赖 Garmin 的隐私政策，因为其中只描述 *Garmin 自身的隐私做法*。

- **权限：** 在适当情况下，应在收集位置数据或可能被视为敏感的数据前征得用户许可。获得许可后，只能按照许可的范围使用数据。您需要负责履行取得同意的法律义务，即使这要求您在具体场景中采取 Connect IQ 框架之外的措施。

**4.** **推广和变现您的应用**

我们希望用户下载、安装并使用您的应用。推广应用首先要在 Connect IQ 商店提供清晰有力的描述，也可以在您自己的渠道中宣传应用。我们希望您以公平、合法和透明的方式进行广告宣传。

**a.** **准确、完整地描述应用**

不得作出不准确或误导性的陈述。向应用商店提交应用时，提供的信息应完整描述所有功能，以及任何最低要求、限制或依赖关系。无论广告是否出现在 Garmin 的数字产品上，这一要求也适用于您为应用开展的其他广告，以及与应用相关的内容或元数据。

具体而言，您必须：

- 使用您本人或公司的真实姓名，或不会冒充他人或其他公司的别名；

- 保持联系信息为最新；

- 除非获得我们的明确书面许可，不得声称与 Garmin 存在合作或关联关系；

- 如果没有获得支持兼容性声明所需的认证，不得声称应用兼容任何第三方系统或协议；

- 说明应用运行是否需要特定的 Garmin 或第三方硬件或软件。例如，如果应用的核心功能必须依赖 ANT+ 才能工作，您必须披露这一点。如果某项功能存在依赖关系，在宣传该功能时必须披露依赖关系。

**b.** **与 Garmin 设备及 ANT 或 ANT+ 通信协议的兼容性**

您必须准确说明哪些 Garmin 设备支持应用。由于 Garmin 会定期发布新产品，我们建议您及时更新设备列表。至少，您必须避免虚假声称应用适用于某款 Garmin 设备。

如果应用支持 ANT 或 ANT+ 配置文件，必须列出应用支持的全部配置文件。此外，在适用情况下，应用必须通过 ANT+ 认证。

**c.** **不得操纵评价或评分**

不得实施或鼓励任何制造虚假评价或操纵应用评分的行为。

具体而言，您**不得**：

- 冒充用户，为自己的应用发布好评或为其他开发者的应用发布差评；

- 以支付报酬或提供产品折扣等方式换取好评或高评分，即使您向评价者披露了与其之间的实质关系；

- 为自己的应用提交评分。

**d.** **应用变现**

您必须说明应用是否需要付费。如果用户必须付费才能访问或使用应用的任何主要功能（即应用描述中宣传的功能，不包括明确标记为可选的功能），则该应用需要付费。相反，如果只有可选功能需要付费或订阅，则应用不被视为必须付费。

描述任何付款要求时，无论付款是否可选，都必须诚实。您必须：

- 如果应用只在有限时间内或只允许有限次数免费使用，从一开始就明确说明；

- 告知用户退款政策，或明确说明没有退款政策；

- 不得以暗示某项功能免费、实际却不免费的方式误导用户；

- 无论法律是否要求，都必须为自动续费取得用户的明确同意。

**5.** **执行**

如有必要，Garmin 将通过拒绝或下架应用来执行本指南，以制止或防止违规行为。Garmin 可以自行决定联系开发者并要求修改应用，但在暂停或下架应用前没有必须通知开发者的义务。

**a.** **审核流程**

提交应用审核时，我们希望应用已经准备好并符合本指南的全部要求。我们会尽力尽可能彻底、及时地审核应用及相关文档。请注意，即使应用通过审核，我们也可能在审核流程结束后发现问题。

**b.** **下架流程**

如果我们发现应用存在问题，无论问题是由我们发现还是由用户向我们反映，我们会尽力给予开发者根据反馈重新提交的机会。如果问题会给 Garmin 或用户带来重大风险，我们可能立即暂停应用的下载或使用。我们没有义务在采取措施前提供通知或处理流程。

**c.** **权利保留**

Garmin 保留采取一切必要措施保护用户、产品、品牌和声誉等方面权益的权利。这意味着即使我们下架应用，仍可以行使所有可用的法律救济或衡平法救济。

**d.** **联系我们**

虽然我们有权执行本指南，但希望尽量避免采取措施。我们希望您的应用取得成功。如果您对 Connect IQ 或本指南有疑问，欢迎在[开发者论坛中提问](https://forums.garmin.com/developer/connect-iq/)。
