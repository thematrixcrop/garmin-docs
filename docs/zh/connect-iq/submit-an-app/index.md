# 提交应用

## 提交应用

应用完成测试并准备就绪后，就可以发布和推广应用。

### 准备提交应用

1. 确认应用的 manifest 指定了要支持的所有产品。
2. 在 Visual Studio Code 的 Monkey C 扩展中使用 *Monkey C: Export Project* 命令，生成包含所有目标产品二进制文件的 `.iq` 文件。
3. 选择该命令后，按照向导提示创建 IQ 文件。
4. 点击 *Finish* 生成应用包。也可以点击 *Next* 更新支持的语言列表，然后再导出。只要没有错误，应用就可以发布。

### 发布第一个版本

第一步是将 IQ 文件上传到 Connect IQ 商店。

二进制文件通过验证后，可以添加应用描述和屏幕截图。请尽量具体地介绍应用，这是吸引用户下载应用的机会。



[提交应用](https://apps.garmin.com/en-US/developer/upload)



![](/static/calendar-d9c3054da75fa33ed71c58c9b1570ce8.svg)

#### 审批流程

成功上传应用后，Garmin 会对其进行审核。您可以预览应用并自行下载测试。审核期间，应用不会显示在 Connect IQ 商店中。审核通过后，我们会通知您，应用也会出现在 Connect IQ 商店，供用户下载到自己的设备。

#### 通用指南

我们很高兴您想开发 Connect IQ 应用，也希望您顺利完成发布。开发应用时，请牢记[相关指南](/connect-iq/app-review-guidelines/)，这些指南有助于加快审核流程。

请注意，这些指南可能随时发生变化。
