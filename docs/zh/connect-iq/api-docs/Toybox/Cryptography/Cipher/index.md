## 实例方法详情

### **decrypt(ciphertext as [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/))** as [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/)

根据密码的初始化方式，使用密钥解密数据。

解密可以拆分为两次或更多次 decrypt() 调用。对于 MODE\_CBC，`ciphertext` 的长度（以字节为单位）必须是块大小的倍数。

参数：

- ciphertext — ([Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/)) —

    要解密的数据片段


返回：

- [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/) —

    已解密的数据


起始版本：

API 级别 3.0.0

抛出：

- ([Lang.UnexpectedTypeException](/connect-iq/api-docs/Toybox/Lang/UnexpectedTypeException/)) —

    若提供 [ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/) 以外的类型则抛出

- ([Cryptography.InvalidBlockSizeException](/connect-iq/api-docs/Toybox/Cryptography/InvalidBlockSizeException/)) —

    如果 `ciphertext` 对所选加密类型而言不是有效大小，则会抛出此异常


### **encrypt(plaintext as [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/))** as [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/)

根据密码的初始化方式，使用密钥加密数据。

加密可以拆分为两次或更多次 encrypt 调用。对于 MODE\_CBC，`plaintext` 的长度（以字节为单位）必须是块大小的倍数。

参数：

- plaintext — ([Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/)) —

    要加密的数据片段


返回：

- [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/) —

    加密数据


起始版本：

API 级别 3.0.0

抛出：

- ([Lang.UnexpectedTypeException](/connect-iq/api-docs/Toybox/Lang/UnexpectedTypeException/)) —

    若提供 [ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/) 以外的类型则抛出

- ([Cryptography.InvalidBlockSizeException](/connect-iq/api-docs/Toybox/Cryptography/InvalidBlockSizeException/)) —

    如果 `plaintext` 对所选加密类型而言不是有效大小，则会抛出此异常


### **initialize(options as { :algorithm as [Cryptography.CipherAlgorithm](/connect-iq/api-docs/Toybox/Cryptography/#CipherAlgorithm-module), :mode as [Cryptography.EncryptionMode](/connect-iq/api-docs/Toybox/Cryptography/#EncryptionMode-module), :key as [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/), :iv as [Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/) })**

Constructor

参数：

- options — ([Lang.Dictionary](/connect-iq/api-docs/Toybox/Lang/Dictionary/)) —

    选项字典

- :algorithm — ([Cryptography.CipherAlgorithm](/connect-iq/api-docs/Toybox/Cryptography/#CipherAlgorithm-module)) —

        此密码对象将使用的加密类型，取自 [CIPHER\_\*](/connect-iq/api-docs/Toybox/Cryptography/) 枚举（必需）

- :mode — ([Cryptography.EncryptionMode](/connect-iq/api-docs/Toybox/Cryptography/#EncryptionMode-module)) —

        此密码对象将使用的加密模式，取自 [MODE\_\*](/connect-iq/api-docs/Toybox/Cryptography/) 枚举（必需）

- :key — ([Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/)) —

        密码中使用的密钥。密钥长度必须适合所选的加密类型（必需）

- :iv — ([Lang.ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/)) —

        用于加密或解密的初始化向量。如果未提供，对于需要初始化向量的算法，系统将使用安全随机字节生成该向量（可选）


起始版本：

API 级别 3.0.0

抛出：

- ([Lang.UnexpectedTypeException](/connect-iq/api-docs/Toybox/Lang/UnexpectedTypeException/)) —

    如果为 `:key` 和 `:iv` 选项提供了 [ByteArray](/connect-iq/api-docs/Toybox/Lang/ByteArray/) 以外的类型，则会抛出此异常

- ([Lang.InvalidOptionsException](/connect-iq/api-docs/Toybox/Lang/InvalidOptionsException/)) —

    如果未提供所需选项、`:algorithm` 和 `:mode` 选项未使用有效枚举初始化、为所选算法提供了无效密钥大小，或为所选算法提供了无效初始化向量大小，则会抛出此异常
