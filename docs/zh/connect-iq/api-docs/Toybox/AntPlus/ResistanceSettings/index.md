## Overview

Represents the basic resistance percentage set on fitness equipment when the equipment is in basic resistance training mode. Fields may return `null` so you should `null` check values before using them.

Since:

API Level 2.4.0

-   Edge® 1000 / Explore
-   Edge® 1030 / Bontrager

-   Edge® 1030
