- a. **注册和应用提交流程。** 要提交应用，您必须遵守以下要求：

    - 3\. **最低年龄。** 创建开发者账户并提交应用时，您必须年满 18 岁。
    - 4\. **应用提交。** 提交应用即表示并保证：
        - A. 应用符合应用要求。
        - B. 您不会试图向 Garmin 隐瞒、歪曲或掩盖应用中的任何功能、内容、服务或行为，也不会妨碍 Garmin 对应用进行完整审核。

        - A. 您会准确提供 Garmin 在入驻过程中或为保持账户良好状态而不时要求的任何信息，包括身份验证所需的信息。
        - B. 您会准确向最终用户披露付款要求的范围，并履行所有相关购买。
        - C. 如果使用 Garmin 未提供的支付处理商，您会确保该支付方式的安全性。
    - 2\. **使用 Garmin 商户服务。** 您不必使用商户服务来变现应用，但如果选择使用，则必须遵守本节要求。
        - A. **受支持的国家/地区。** 您必须位于受支持的国家/地区才能使用商户服务。受支持国家/地区的信息见文档。
        - B. **市场账户。** 您必须根据与 Garmin 授权的支付处理商和市场平台提供商签订的单独协议，拥有有效账户（“**商户账户**”），并保持该账户处于良好状态。
